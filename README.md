# Blood Cell Classification Capstone

## Project Overview
An image-classification project using the PBC dataset to classify blood-cell images into the dataset's verified categories.

## Planned Features
- Dataset inspection and preprocessing
- Transfer-learning baseline
- Class-wise model evaluation
- Confusion matrix and classification report
- Image prediction interface using Streamlit
- Optional explainability using Grad-CAM

## Project Status
Initial project setup completed. Dataset inspection and model development are pending.

## Important Note
This project is for educational and research purposes only and is not intended for clinical diagnosis.
