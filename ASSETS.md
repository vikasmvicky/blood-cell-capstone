# Excluded assets and how to restore them

Nothing below is fabricated or substituted; the code reports clearly when an asset is missing.

| Asset | Expected location | Needed for | How to obtain |
|---|---|---|---|
| Trained checkpoint `best_mobilenet_finetuned.pt` | `outputs/models/best_mobilenet_finetuned.pt` (or `$BLOOD_CELL_MODEL_PATH`) | website predictions, evaluation, benchmark (real weights), robustness, experiments | Produced by `python -m src.models.train_mobilenet_finetune` (the original run came from `Blood_Cell_CNN_Training.ipynb`, which is not in this archive). Copy your existing file here. Not bundled: it was not in the uploaded ZIP and `*.pt` is git-ignored by design. |
| PBC dataset images (`PBC_dataset_normal_DIB`, 8 class folders, 17,092 images) | `data/raw/PBC_dataset_normal_DIB/<class>/*.jpg` (or `$BLOOD_CELL_DATA_ROOT`) | training, evaluation, robustness, experiments | Public PBC dataset (Acevedo et al., Data in Brief 2020, Mendeley Data). Not redistributed here. |
| Split manifest `splits.csv` | `outputs/reports/splits.csv` | any dataset-based command | `python -m src.data.inspect_dataset` then `python -m src.data.split_dataset --seed 123`. The recorded split used seed **123** (`split_summary.json`); the script's default seed is 42, so pass `--seed 123` to reproduce it. |
| Image manifest `image_manifest.csv` | `outputs/reports/image_manifest.csv` | input to `split_dataset` | Created by `inspect_dataset`. |
| `mobilenet_finetuned_summary.json`, test metrics/report CSV/JSON | `outputs/reports/` | provenance of the historical result | Regenerated by training / `run_evaluation`. |
| `calibration.json` (optional) | `outputs/reports/calibration.json` | temperature-scaled probabilities in the website | `python -m src.evaluation.run_evaluation --calibrate` (bound to the checkpoint's SHA-256; ignored for any other checkpoint). |

Image paths inside `splits.csv` may be absolute paths from the original Windows machine (`D:\...`); the loader automatically
falls back to `data_root/<rel_path>`, so no editing is needed.

Checkpoint loading uses `torch.load(..., weights_only=True)`, validates architecture, class count and class order
against `outputs/reports/class_to_idx.json`, and refuses incompatible files.
